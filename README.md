# ASCII Rainy Café

A cozy rainy window, drawn entirely with text characters. Raindrops gather and slide down the glass, the city glows outside, a cat naps on the windowsill next to a steaming mug, and string lights twinkle overhead. Outside follows your real clock: grey and rainy by day, glowing city lights at night.

## Controls

| Action | What it does |
| --- | --- |
| Drag on the window | Wipe the fog off the glass (or draw on it!) |
| Tap the cat | Wake it up for a meow and a purr |
| Tap the mug | Take a sip (tap when empty for a refill) |
| `R` or the rain button | Drizzle → rain → thunderstorm |
| `L` or ♪ lofi | Lofi music |
| `M` or sound | Rain, taps on the glass, purring, sips and thunder |
| `C` / `H` | Show / hide the clock · 12 / 24-hour |
| `Space` | Pause |

## Run it

Open `index.html` in any browser. No install or build step: it's one self-contained file.
